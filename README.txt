Ejercicio final de HTML Incluye:

- index.html: portada con 3 secciones.
   -Descripción: Página principal del sitio web.
    seguridad: Se han implementado medidas de seguridad básicas, como la validación de entradas y el uso de HTTPS.
    accesibilidad: Se han seguido pautas de accesibilidad web, incluyendo el uso de header, nav, main, section y footer, así como etiquetas
    semánticas y texto alternativo para imágenes.
    optimización: Se han optimizado las imágenes y el código para mejorar la velocidad de carga y la experiencia del usuario. 

- productos.html: galería en cuadrícula.
    -Descripción: Página del producto.
    Contenido: Se ha creado una galería de proyectos web con imágenes y descripciones.
    Etiquetas: Se han utilizado etiquetas semánticas como nav, main, footer, article y section para estructurar el contenido.

- presupuesto.html: formulario HTML5 con validación y política de privacidad.
    -Descripción: Página del presupuesto.
    Contenido: Se ha creado un formulario de solicitud de presupuesto con campos para nombre, email, teléfono e información adicional.  
    Etiquetas: Se han utilizado etiquetas semánticas como nav, main, footer, section y form para estructurar el contenido.
    Labels: Se han utilizado etiquetas label para asociar los campos del formulario con sus respectivas descripciones, mejorando la accesibilidad.
    checkbox: Se ha incluido un checkbox para que el usuario acepte la política de privacidad antes de enviar el formulario, cumpliendo con las normativas de protección de datos.

- contacto.html: datos de empresa y mapa.
    - Descripción: Página de contacto.
    Contenido: Se ha creado una sección con información de contacto y un mapa de ubicación.
    Etiquetas: Se han utilizado etiquetas semánticas como nav, main, footer y section para estructurar el contenido.
    strong: Se ha utilizado la etiqueta strong para resaltar la información de contacto importante.

- css/estilos.css: estilos comunes.

- img/: carpeta preparada para imágenes locales.
- en todas las paginas se encuentra el logotipo el cual siempre lleva al inicio
- se encuentra un apartado de aviso legal el cual este tiene al pie de la pagina las 3 secciones
